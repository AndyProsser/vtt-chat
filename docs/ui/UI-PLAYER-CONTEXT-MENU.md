# Player Context (Right-Click) Menu

A DM/player can right-click on another player's name in the player list to access a context menu with various options. The available options depend on the permissions of the player and the relationship between the players (e.g., whether they are in the same group).

| Option               | Description                                                                             |
| -------------------- | --------------------------------------------------------------------------------------- |
| Send Private Message | Send a private message to the selected player.                                          |
| View Profile         | View the profile of the selected player.                                                |
| -------------------- | --------------------------------------------------------------------------------------- |
| Mute/Unmute          | Mute or unmute the selected player.                                                     |
| -------------------- | --------------------------------------------------------------------------------------- |
| Clear Effects        | Clear all active effects from the selected player.                                      |
| Distance >           | Set the distance between the selected player and the group. Opens sub-menu on hover.    |
| Condition >          | Add or remove conditions from the selected player. Opens sub-menu on hover.             |
| -------------------- | --------------------------------------------------------------------------------------- |
| Kick Player          | Remove the selected player from the campaign.                                           |
| Ban Player           | Ban the selected player from rejoining the campaign.                                    |
| -------------------- | --------------------------------------------------------------------------------------- |
| Grant/Revoke DM Priv | Grant or revoke Assistant Dungeon Master privileges for the selected player.            |
| -------------------- | --------------------------------------------------------------------------------------- |

First 2 items are available for all players. The rest of the options are only available to DMs and Assistant DMs, and the Grant/Revoke DM Priv option is only available to DMs.

**Distance Sub-menu:**

| Option      | Description                                                                                     |
| ----------- | ----------------------------------------------------------------------------------------------- |
| Default     | Set the distance between the selected player and the group to the default distance (None).      |
| Nearby      | Set the distance between the selected player and the group to "Nearby".                         |
| Visible     | Set the distance between the selected player and the group to "Visible".                        |
| Far         | Set the distance between the selected player and the group to "Far".                            |
| ----------- | ----------------------------------------------------------------------------------------------- |

**Condition Sub-menu:**

| Option        | Description                                                                                     |
| ------------- | ----------------------------------------------------------------------------------------------- |
| Default       | Remove all conditions from the selected player.                                                 |
| Blinded       | Add the "Blinded" condition to the selected player.                                             |
| Charmed       | Add the "Charmed" condition to the selected player.                                             |
| Confused      | Add the "Confused" condition to the selected player.                                            |
| Cursed        | Add the "Cursed" condition to the selected player.                                              |
| Deafened      | Add the "Deafened" condition to the selected player.                                            |
| Drunk         | Add the "Drunk" condition to the selected player.                                               |
| Exhausted     | Add the "Exhausted" condition to the selected player.                                           |
| Frightened    | Add the "Frightened" condition to the selected player.                                          |
| Grappled      | Add the "Grappled" condition to the selected player.                                            |
| Incapacitated | Add the "Incapacitated" condition to the selected player.                                       |
| Invisible     | Add the "Invisible" condition to the selected player.                                           |
| Paralyzed     | Add the "Paralyzed" condition to the selected player.                                           |
| Petrified     | Add the "Petrified" condition to the selected player.                                           |
| Poisoned      | Add the "Poisoned" condition to the selected player.                                            |
| Prone         | Add the "Prone" condition to the selected player.                                               |
| Restrained    | Add the "Restrained" condition to the selected player.                                          |
| Silenced      | Add the "Silenced" condition to the selected player.                                            |
| Stunned       | Add the "Stunned" condition to the selected player.                                             |
| Unconscious   | Add the "Unconscious" condition to the selected player.                                         |
| -----------   | ----------------------------------------------------------------------------------------------- |

Some options may apply an audio effect to the player (e.g., "Deafened" condition may apply a muffled audio effect).
Others may apply a visual effect to the player's token (e.g., "Invisible" condition may make the player's token semi-transparent).
