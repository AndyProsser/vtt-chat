## 1) Scope and Contract Lock

This checklist implements the locked Notes/Journal contract:

- Journal is exactly one item per session chapter.
- Journal name is linked to session name/chapter name.
- Notes and Journal require: Name, Content (markdown), Hashtags, Attachments.
- Editor defaults to rich markdown with helper toolbar and raw markdown toggle.
- External links are blocked in editor and renderer.
- Internal note links and attachment links are allowed.
- Notes sharing scopes: PRIVATE, PARTY, SELECTED, SPECTATORS.
- DM note sharing surfaces a one-time recipients-only chat card.
- Handout card excerpt is auto-generated by default; DM override is optional.
- Search is basic text only over Name + Content + Hashtags for this stage.

Out of scope for this stage:

- AI content generation.
- Advanced search filters (date/author/attachment/type).
- Full markdown plugin ecosystem expansion beyond current DMDX and helper toolbar.

### 3.7 Excerpt Generation Algorithm

Use this deterministic algorithm for one-time handout card excerpts.

Input:

- Source markdown content from note/journal at surface time.
- Optional DM manual override text.

Rules:

1. Manual override wins:

- If override is present and non-empty after trim, sanitize and use it.

2. Normalize source text:

- Strip markdown syntax and HTML tags.
- Remove link URLs and preserve link label text only.
- Replace attachment tokens with readable placeholders (for example, "[image]", "[pdf]").
- Collapse whitespace to single spaces and trim.

3. Sentence-first extraction:

- Target max length: 180 characters.
- Hard cap: 220 characters.
- Prefer the first complete sentence that fits within 180 characters.
- If first sentence exceeds 180, cut at nearest word boundary <= 180 and append "...".
- If no sentence punctuation exists, cut at nearest word boundary <= 180 and append "..." when truncated.
- Never exceed 220 characters.

4. Fallback priority when normalized text is empty or too sparse:

- Fallback A: note/journal name.
- Fallback B: attachment summary (for example, "Shared attachment: 1 image, 1 pdf").
- Fallback C: fixed copy "Shared handout".

5. Safety:

- Excerpt must not include external URLs.
- Excerpt must be plain text only.
- Output must be deterministic for identical input.

Payload fields:

- `excerpt`: final text after algorithm.
- `excerptSource`: `MANUAL` when override used, otherwise `AUTO`.
