# Security Policy

## Supported Versions

The table below lists which versions of VTT-Chat currently receive security updates. Only the latest 0.5.x series is actively supported; all earlier versions do not receive security patches. For the best security, always use the latest supported release.

| Version | Supported          |
| ------- | ------------------ |
| 0.5.x   | :white_check_mark: |
| < 0.5   | :x:                |

## Reporting a Vulnerability

To report a security vulnerability, please follow these steps:

1. **Contact**: Open a private security advisory via the GitHub repository's "Security" tab.
2. **Details**: Include as much information as possible, such as steps to reproduce, potential impact, and any relevant logs or screenshots.
3. **Response Time**: You will receive an initial response within 3 business days. We may contact you for further information if needed.
4. **Process**: Once a vulnerability is confirmed, we will work to address it as quickly as possible. You will be kept informed of the progress and notified when a fix is released.
5. **Disclosure**: Please do not publicly disclose the vulnerability until we have had a chance to investigate and provide a fix.

Thank you for helping us keep this project secure!
