# Code of Conduct  
*For the VTT‑Chat Project*

---

## 📜 Our Pledge

We, the maintainers and contributors of **VTT‑Chat**, pledge to make participation in this project a **welcoming, harassment‑free, and respectful experience** for everyone.

This project exists to support tabletop gaming communities — DMs, players, hobbyists, and homebrew creators. We want this space to reflect the same spirit of collaboration and creativity that makes tabletop gaming special.

---

## 🤝 Our Standards

### We strive to foster an environment where people:

- Are **respectful** and **considerate**  
- Offer **constructive feedback**  
- Collaborate in good faith  
- Show empathy toward others  
- Help maintain a positive and productive community  
- Assume good intent unless proven otherwise  

### Unacceptable behavior includes:

- Harassment, discrimination, or personal attacks  
- Demeaning or insulting comments  
- Deliberate intimidation or threats  
- Disruptive or hostile behavior  
- Sharing private information without consent  
- Any conduct that makes others feel unsafe or unwelcome  

---

## 🧭 Our Responsibilities

Project maintainers are responsible for:

- Clarifying standards of acceptable behavior  
- Reviewing and moderating contributions  
- Taking appropriate action when unacceptable behavior occurs  
- Removing or rejecting contributions that violate this Code of Conduct  
- Temporarily or permanently banning contributors for severe or repeated violations  

---

## 🛠️ Scope

This Code of Conduct applies to:

- The GitHub repository  
- Issues, pull requests, and discussions  
- Project documentation  
- Community spaces related to VTT‑Chat  
- Any public interactions where someone represents the project  

This includes interactions in:

- GitHub Issues  
- Pull Request discussions  
- Project‑related chat or forums  
- Documentation contributions  
- External community spaces where the project is referenced  

---

## 🚨 Enforcement

If you witness or experience unacceptable behavior:

👉 **Please open an Issue** (if appropriate)  
or  
👉 **Privately contact the project maintainer** via GitHub

All reports will be reviewed and investigated promptly and fairly.

Maintainers are obligated to respect the privacy and security of reporters.

---

## 🧱 Consequences

Violations may result in:

- A warning  
- Temporary or permanent ban from contributing  
- Removal of comments, issues, or pull requests  
- Escalation to GitHub if necessary  

The severity of consequences will match the severity of the behavior.
