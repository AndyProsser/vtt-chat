# VTT-Chat Frontend

This is the frontend SPA for **VTT-Chat**, a DM-grade, session-aware tabletop voice & chat platform.

Technologies:

- React + TypeScript
- Vite
- Zustand state management
- LiveKit client SDK
- WebSocket realtime events
- Web Audio API

This SPA provides:

- Chat UI
- Metadata timeline
- Notes panel
- DM audio controls
- Player audio controls
- Room management
- Avatar overlays
- Session boundary UI

Part of the larger VTT-Chat project.
